# tools

Hub repository for tools and helpers built around Claude Code (and future
related tooling).

## Contents

### claude-code-tools/

Tools that integrate with [Claude Code](https://claude.com/claude-code).

- [claude-code-cognee-graph-memory](claude-code-tools/claude-code-cognee-graph-memory/) —
  Cross-session graph memory for Claude Code, powered by
  [Cognee](https://github.com/topoteretes/cognee) + Ollama + FastEmbed.
  Runs fully locally with no external API keys or fees.
